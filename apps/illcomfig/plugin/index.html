Illustration Composer · плагин для Figma

Собирает композиции внутри Figma из готовых образцов библиотеки: без новых объектов, с перекраской по палитре и подменой состояний (главный / фоновый) и размера (L / S).

Установка (2 минуты)

  1. Скачайте три файла ниже в одну папку: manifest.json, code.js, ui.html.
  2. Откройте Figma → меню Plugins → Development → Import plugin from manifest…
  3. Выберите скачанный manifest.json.
  4. Откройте файл с библиотекой и запустите Plugins → Development → Illustration Composer.

Что умеет

  • Сборка по метафоре — выбирает один из 18 готовых образцов страницы «Примеры композиций» и вставляет его копию как есть (компоновка, масштаб и порядок слоёв не меняются).
  • Перекраска — заменяет только цвета слотов палитры (фоновые / объектные), формы и структура векторов не затрагиваются. Работает и на выделенном фрейме.
  • Фоновые объекты — подменяет каждый объект композиции на его монохромный вариант из библиотеки, сохраняя позицию и размер.
  • Размер L / S — подставляет вариант нужной детализации с равномерным масштабированием.
  • Своя палитра — загрузка JSON вида {"bg":["#…"],"obj":["#…"]}.

Как это работает

Плагин не рисует новые объекты. Он строит индекс узлов библиотеки: секции «Размер L» и «Размер S», в них — объекты и фоны; монохромный вариант отличается от главного по составу заливок (в монохроме нет объектных цветов палитры). Дальше — node.clone() нужного узла, insertChild на место исходного и rescale под прежний размер. Цвета меняются только в SOLID-заливках и обводках по таблице ролей.
